Propositional logic exercises

Notation: ~ (not), \(\wedge\) (and), \(\lor\) (or), \(\rightarrow\) (if…then), \(\leftrightarrow\) (if and only if)

In your document you can use annotation for these connectives:

  • tilde for negation
  • $\wedge$ for ‘and’
  • $\lor$ for ‘or’
  • $\rightarrow$ for ‘if…then’
  • $\leftrightarrow$ for ‘if and only if’

Illustration. We consider the sentence

If Ana studies, then if she rests well, she will pass the exam.

We can use propositional variables

  • S = Ana studies
  • R = Ana rests well
  • P = Ana passes the exam

We will formalize the sentence as \(S \rightarrow (R \rightarrow P)\), and suppose that the sentence is TRUE. If Ana rested well and failed the exam, what can we say about whether she studied? Give all your reasoning.

A formal approach could be based on writing out the truth table.

S R P S → (R → P)
T T T T
T T F F
T F T T
T F F T
F T T T
F T F T
F F T T
F F F T

We asserted that the sentence is true but P is false and R is true. We can find this configuration only once in the truth table, on the sixth line. There S is F, so we conclude that Ana did not study.

Note that when I submitted the problem to the Luna chatbot in the Harvard sandbox, it found

“This is an application of modus tollens to the outer implication: if \(S\) were true, then \(R \rightarrow P\) would have to be true, but it is false. Therefore \(S\) must be false.”

That’s interesting. I should be motivated to learn what modus tollens is, might connect it to modus ponens, and might learn a short cut relative to working out the truth table.
